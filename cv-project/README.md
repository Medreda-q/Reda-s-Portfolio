Instead of a PDF that goes out of date, I built my CV as a website.  
It loads fast, works on any device, comes in three languages and two themes "Light and dark".

> Live at : 🔗 [mohamedreda.is-a.dev/CV](https://mohamedreda.is-a.dev/CV)

---

## What's inside

A straightforward CV covering:

- Education
- Cybersecurity projects
- Technical skills and tools
- Certifications
- Contact links

Available in **English**, **French**, and **Spanish**.

---

## Stack
- **Generator** : | Hugo |
- **Styling** : | CSS3 | i18n | Hugo multilingual mode (EN / FR / ES) |
- **Deployment** : | Vercel |
- **Domain** : | is-a.dev custom subdomain |
  
---

## Structure

```
reda-s-CV/
├── config.toml              # Site config & language setup
├── data/                    # Dynamic site content
│   ├── content.en.yaml      # English data source
│   ├── content.fr.yaml      # French data source
│   └── content.es.yaml      # Spanish data source
├── layouts/                 # HTML templates
├── i18n/                    # Translation dictionaries
├── assets/                  # Stylesheets (SCSS)
└── static/                  # Static assets (PDFs, images)
```
